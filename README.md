# しずくソート 💧

透明な液を試験管で注ぎ分ける、ウォーターソートパズル。ブラウザだけで遊べます（インストール不要・1ファイル）。

## あそびかた
- 試験管をタップ → 別の試験管をタップで注ぐ
- 注げるのは「一番上が同じ色」か「空の試験管」だけ。入りきる分だけ注がれます
- 全部の試験管を1色ずつにそろえたらクリア

## レベルが上がると
| レベル | 変化 |
|---|---|
| 1〜 | 3色からスタート、3レベルごとに1色ずつ増加（最大12色） |
| 8〜 | 下の色が隠れる（上2つだけ見える） |
| 15〜 | 一番上しか見えない。上を移すと下の色がわかる |
| 36〜 | 試験管が5層に |

盤面はレベル番号から毎回同じものが作られるので、友だちと「Lv20何手でいけた？」と比べられます。全レベル、自動ソルバーで解けることを確認済み。

## 助っ人機能
- ↶ 戻す（1レベル5回まで）
- 💡 ヒント（1レベル3回まで・次の一手を光らせる）
- ＋ 試験管（1レベル1回だけ）
- ⟳ やり直し

## セーブ
進み具合は自動でブラウザ（localStorage）に保存されます。別の端末へは「⚙︎ → 今のデータをコードにする」で出したコードを貼り付けて引っ越しできます。

## GitHub Pages で公開する
1. このリポジトリに `index.html` を置いて push
2. Settings → Pages → Branch を `main` / `(root)` にして Save
3. 数分後 `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます

※ iPhone はマナーモード（消音スイッチ）だと音が出ません。
