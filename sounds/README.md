# 注ぐ音（本物の録音）の入れ方

このフォルダに **`pour.mp3`**（`pour.ogg` / `pour.wav` でもOK）を置くと、
ゲームは注ぐたびにその録音を鳴らします。録音は加工せず、注ぐ長さに合わせて切り出し、始めと終わりだけなめらかにします。
置いていない時は、代わりに作った音が鳴ります。

## 録音えらびのコツ
- 急須で湯のみに注いでいる、**3〜6秒くらいの録音**（長めの方が毎回ちがう部分が鳴って自然）
- 最初と最後に無音や雑音があれば切っておく

## ライセンスに注意（GitHubで公開するので）
- いちばん安心なのは **CC0**（誰でも自由に使えて、クレジットも不要）。
  Freesound（freesound.org）で「pouring tea」などと検索し、ライセンスを CC0 に絞ると探せます（ダウンロードには無料登録が必要）。
- 国内のフリー効果音サイトの音を使う場合は、各サイトの利用規約（とくに「素材の再配布」）を確認してください。
- クレジットが必要なライセンス（CC-BY など）なら、トップの README に作者名とリンクを書いてください。

## 確認のしかた
index.html をダブルクリックで開いた時は、ブラウザの制限で録音は読み込まれません（代わりの音が鳴ります）。
GitHub Pages で開くと録音が鳴ります。
